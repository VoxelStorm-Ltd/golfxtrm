GolfXTRM by Riot
http://golfxtrm.com


Controls:
    WASD to walk,
    shift to run,
    space to jump,
    hold left mouse button to move arms,
    hold right mouse button to move arms and head,
    hold both mouse buttons at the same time to move just your head.
    B to drop an extra ball
    O and P to switch between filled and wireframe rendering

Commandline options:
    -skipintro        disable the splash screen and intro music
    -fullscreen       load fullscreen
    -largewindow      load in a window sized a bit below desktop size (default)
    -smallwindow      load in a smaller window
    -novao            disable vertex array objects - may fix startup crashes on old hardware
    -width x          set the window width to x (with -smallwindow only)
    -height y         set the window heigt to y (with -smallwindow only)
    -timespeed t      set the multiplier for the speed of time passage for the world (default = 120)
    -golfballspeed t  set the multiplier for the ball physics to t (default = 1)

Tip: Try setting time speed to 86400 for 1-day-a-second speed, to watch seasons change and trees slowly grow.

Tip: Try setting physics update speed to 0.01 to watch the ball fly in beautiful slow motion.
